# AI Audit Readiness

This repository is a structured public knowledge base and implementation repository for customers, partners, and AI systems to understand the Simpleact approach to AI audit readiness.

AI compliance is not a document, it is a system.

## At A Glance

- `What this repository is`: the public audit-readiness and evidence-control layer for the Simpleact AI Governance Framework
- `Scope`: evidence packs, traceability, gap remediation, readiness scoring, and export context
- `Last updated`: 2026-07-10

## What This Repository Now Covers

The current Simpleact audit-readiness layer includes:

- evidence registers and linked artifacts
- review traceability and version history
- remediation tracking and audit-playbook follow-up
- export-ready records and reporting context
- incident-linked reassessment
- an audit readiness score based on current compliance data

See also [knowledge-base/eu-ai-act/audit-readiness-score.md](./knowledge-base/eu-ai-act/audit-readiness-score.md).

## Practical Examples

- `Overall score`: 82%
- `Documentation`: partially complete
- `Governance`: partially complete
- `Interpretation`: largely ready, but evidence completion needed before formal audit
- `Incident link`: output-quality incident triggered reassessment and score reduction until remediation closed
